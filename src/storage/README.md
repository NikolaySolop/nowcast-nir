# storage

Модуль отвечает за работу с PostgreSQL.

Типовые задачи:

- создание SQLAlchemy engine/session;
- описание первых ORM-схем;
- функции сохранения статусов ingestion-запусков;
- сохранение raw payload от внешних источников;
- чтение данных для следующих слоев проекта.

На текущем этапе таблицы могут создаваться автоматически через
`AUTO_CREATE_TABLES=true`. Позже, когда схема станет стабильнее, это лучше
заменить на миграции Alembic.
