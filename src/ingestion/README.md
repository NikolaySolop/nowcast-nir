# ingestion

Модуль отвечает за сбор данных из внешних источников.

Типовые задачи:

- клиенты для внешних API;
- scraping сайтов;
- загрузка файлов;
- первичная проверка ответа источника;
- сохранение raw payload и статуса запуска через `storage`.

Здесь не должно быть модельной логики. `ingestion` отвечает только на вопрос:
"как надежно получить данные и передать их в хранилище?"
